# PSF scanning and bounded template mixtures — v1.17.21

Contracts frozen before reference vectors and GPU kernels. All arithmetic uses the existing exact RN32 graph: each operation rounds separately, positive canonical zero, no FMA/reassociation. Finite inputs and intermediates only; overflow is rejected before submission. All output bytes, statuses included, must match the independent Fraction oracle with zero differing bits.

## Opcode 59: weighted PSF scan

Image, supplied background, and nonnegative inverse-variance planes have equal shape H,W in 1..64. Supplied nonnegative PSF has odd dimensions 1..9 and a positive sum. No automatic normalization: amplitude means coefficient of the supplied PSF; it is total flux only for a unit-sum PSF. Each row-major image pixel is a proposed integer PSF center. Partial support returns status 2 and five zero fields; no crop, padding, or edge renormalization. Full-support pixels with weight zero contribute no information. Independent pixel errors and known fixed background are assumed.

For each center, visit the PSF in row-major order. d=RN(image-background), wp=RN(weight*PSF), numerator+=RN(wp*d), denominator+=RN(wp*PSF). If denominator is zero return status 1 and five zero fields. Otherwise amplitude=numerator/denominator; variance=1/denominator; snr=amplitude/sqrt(variance). Revisit support in the same order: residual=RN(d-RN(amplitude*PSF)); chi2+=RN(weight*RN(residual*residual)). Output [u32 status, f32 amplitude,variance,snr,chi2,u32 positive_weight_pixels]. Signed amplitude and SNR are retained; no significance or multiple-testing claim. SNR is a local known-noise diagnostic, not detection certification.

## Opcode 60: bounded nonnegative template mixtures

Shared nonnegative templates [M,N], M=3..5, N=M..128; flux and nonnegative inverse variance [R,N], R=1..64. Work bound R*2^M*(N*M+M^3)<=2097152. Templates need not be normalized. Input data may be negative. Background subtraction is explicit upstream. One output per observation vector: [u32 status, u32 positive_coefficient_mask, f32 chi2, f32 coefficient[M]].

Construct the symmetric Gram matrix in lower-triangle row/column order: G[a,b]=ordered_sum_j(RN(RN(w[j]*T[a,j])*T[b,j])); mirror the lower triangle. rhs[a]=ordered_sum_j(RN(RN(w[j]*T[a,j])*y[j])). Let scale=max diagonal; scale=0 gives status 1. Threshold=RN(scale*2^-18). Enumerate active subsets in ascending integer mask order, including the all-zero coefficients first. For each nonempty subset, indices increase; solve its principal system by lower Cholesky, ordered forward and reverse substitution. A pivot <= threshold in ANY subset returns status 2 and zero remaining fields, rejecting singular/poorly scaled groups rather than claiming a complete solve. This conservative finite-precision condition gate is not an exact rank or condition-number oracle.

For each feasible subset (all solved coefficients >=0), compute prediction from zero by increasing full template index, then residual=y-prediction, and chi2=ordered_sum_j(RN(w[j]*RN(residual^2))). Retain only strictly lower RN32 chi2; equal objectives retain the earlier mask. Final mask marks strictly positive coefficients, not every solved index. No ridge, clipping of negative coefficients, iterative tolerance, or incomplete active-set search. All 2^M subsets are examined on successful records. This finite RN32 algorithm is diagnosed independently against float64 SVD subset minimization and KKT residuals; it does not assert exact real-arithmetic minimization for arbitrary ill-conditioned inputs.

## Scientific scope and research, 2026-10-03

The scan uses the one-parameter weighted least-squares estimator. [GSL weighted least squares](https://www.gnu.org/software/gsl/doc/html/lls.html) specifies the weighted objective. [Photutils PSFPhotometry](https://photutils.readthedocs.io/en/stable/api/photutils.psf.PSFPhotometry.html) motivates simultaneous overlapping-source fits. [SciPy NNLS](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.nnls.html) documents the nonnegative objective and active-set/KKT family. This implementation instead exhaustively enumerates a bounded 3..5-template set. [LAPACK least squares](https://www.netlib.org/lapack/lug/node27.html) informs independent SVD checks. Original code only; no external implementation copied.

Reviewed families: direct spatial correlation versus FFT convolution, scalar versus tiled PSF gathers, bounded active-subset enumeration versus iterative NNLS, Cholesky versus QR/SVD. Direct ordered evaluation preserves masks, heteroscedastic weights and the stated RN32 reduction order. No tree reductions or floating atomics. [Khronos subgroups](https://docs.vulkan.org/guide/latest/subgroups.html) informs portable candidate scheduling: local 32/64/128/256, pack 1/2/4, all fresh local candidates. Full per-MathSpec QUICK <=60s; unmeasured candidates remain explicitly unmeasured. No historical winner import, no RT pruning or AI execution claim.

Known-position, fixed-PSF group fitting is a bounded form of deblending. It does not estimate a PSF, optimize subpixel positions, infer unknown source counts, handle arbitrary large groups, fit background, model correlated noise or guarantee automatic deblending. The same mixture kernel can fit supplied SED templates without counting that use as another workload.
