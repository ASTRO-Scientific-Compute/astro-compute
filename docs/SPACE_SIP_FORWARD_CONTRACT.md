# Bounded supplied SIP forward pixel distortion — V1

Contract fixed before implementation. Primary definition: Shupe/Hook, SIP convention1.0 section2 equations1–3 (https://fits.gsfc.nasa.gov/registry/sip/SIP_distortion_v1_0.pdf, read2026-10-04 UTC); NASA registry https://fits.gsfc.nasa.gov/registry/sip.html. SIP maps reference-relative pixel offsets u,v to corrected offsets U=u+f(u,v),V=v+g(u,v) before the CD transform; forward f,g contain degree>=2 polynomial terms. The convention permits independent polynomial orders2..9. This original bounded GPU MathSpec implements orders2..5, without copying library code. Registration is not an assertion of IAU FITS standard status or full FITS/WCS compatibility.

## Exact payload

New genuine workload SPACE_SIP_FORWARD_F32_V1, opcode81; polynomial distortion is absent from existing matrix/projection MathSpecs. Exactly encoding=binary32-hex, offset_unit=pixel, offset_origin=REFERENCE_PIXEL, term_order=DEGREE_ASCENDING_P_ASCENDING, model_id(nonblank string<=64), a_order,b_order(integer2..5, bool invalid), a_coefficients,b_coefficients, offsets[N][2]. N1..4096, finite8-hex scalars, |u|,|v|<=1024 incl signed zeros/subnormals. The coefficient arrays must contain exactly one value for each term d=2..order, p=0..d, q=d-p, in that order. No hidden omitted coefficients: supply explicit zeros. For degree d, |coefficient|<=2^(8-10*d); zero/subnormal coefficients allowed. Both orders independent. A degree-d coefficient carries pixel^(1-d) units so each correction is in pixels. Terms of degree0/1 are forbidden. No calibration/fit, clipping, hidden reference subtraction, CD matrix or angular units.

## Canonical graph and packet

For each row make powers up[0]=vp[0]=1, up[k]=RN32(up[k-1]*u), vp[k]=RN32(vp[k-1]*v) for k1..maxorder. Evaluate each channel from+0, degree-ascending then p-ascending: term=RN32(RN32(coefficient*up[p])*vp[q]); sum=RN32(sum+term). The channels stop at their respective orders; no polynomial Horner reassociation, FMA or coefficient pruning. Output4binary32 words [RN32(u+sumA),RN32(v+sumB),sumA,sumB]. All fields are mandatory full-output0-bit gates. Fraction-based independent CPU oracle; Vulkan SOFT32 integer shader implements the declared graph independently. Bounds imply power magnitudes<=2^50, each ideal monomial<=256, at most18terms/channel, finite intermediate/output values; no invertibility or physical calibration guarantee.

Confirmed packet16words header: magic,version1,opcode81,N,a_order,b_order,0,0,0,0,0,A_start,B_start,4,0,0; coordinates begin16 then2N words, A_start=16+2N, B_start=A_start+terms(a_order), followed by coefficientsB. This layout uses the existing packet executor offset conventions. Native opcode ceiling becomes81; old packets unchanged. Independent row partitioning.

## Scientific validation and probes

Independent binary64 dense two-dimensional polynomial evaluation via NumPy polynomial.polyval2d on original supplied coefficients/offsets, not the rounded graph. Check all four output values. Per channel let S=sum |coef*u^p*v^q| in binary64. Correction error/max(1,S)<=8e-6; corrected-offset error/max(1,|u_or_v|+S)<=8e-6. Save absolute and scaled maxima separately; tolerance fixed before tests and never replaces exact-byte checks. Analytic center gives U=V=f=g=+0 (canonical zeros), pure quadratic/cross/cubic monomials, asymmetric orders, sign parity and zero distortion anchors. This is a bounded polynomial model diagnostic, not astrometric calibration evidence. Center derivative identity may be tested analytically; no global inverse/monotonicity promise.
