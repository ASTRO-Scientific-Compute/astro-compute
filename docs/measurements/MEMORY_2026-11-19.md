# 124M training memory replay — 2026-11-19

**VERIFIED: memory reduction on this graph and these devices.** Private source and retained measurement summaries were inspected; no new physical replay was run for this documentation change.

## Matched work

The replay used the same frozen starting weights, 512 training windows, learning rates, FP32 arithmetic, output policy and three-device concurrency as the baseline. The model contains 124,013,568 parameters. There was one matched comparison per GPU, not repeated statistical trials.

| Device | Peak backend buffers (GiB) | Worker E2E (s) | Process-tree CPU (s) | GPU event time (s) |
|---|---:|---:|---:|---:|
| RTX 4060 Ti / CUDA | 2.984 → 2.060 | 185.370 → 212.514 | 29.499 → 31.022 | 149.908 → 147.575 |
| RX 470 ×8 / Vulkan | 3.031 → 2.107 | 580.354 → 624.170 | 33.997 → 34.441 | 508.841 → 506.399 |
| RX 470 ×1 / Vulkan | 3.031 → 2.107 | 642.157 → 641.105 | 63.701 → 33.933 | 510.829 → 507.830 |

Exactly **992,108,544 bytes**, approximately **0.924 GiB**, of peak backend allocation were removed on each device by reducing redundant full-model temporary storage. This is an allocation-lifetime improvement; it does not use lower-precision weights to obtain this result.

Backend buffers are not total driver VRAM, host RSS or whole-system RAM. The measured E2E increased on RTX and RX ×8, and changed little on RX ×1. **There is no general E2E speedup.** Different time measures must not be subtracted to invent a CPU-waste figure.

## Correctness

- All 512 loss values were identical to the baseline on the same device.
- Penultimate and final checkpoints were byte-identical on each device: 992,108,544 compared checkpoint bytes per device in total.
- The complete final update of all 124,013,568 parameters was checked against an independent Float64 calculation on each GPU's preceding state.
- Maximum absolute final-weight error was approximately 5.95919e-8; the worst error used less than 0.248 of its per-value allowed error.

The update contract was `abs(weight_error) <= 2*ulp(round32(Float64_update)) + learning_rate*(2e-5 + 5e-4*abs(Float64_gradient))`. Loss tolerance was absolute `2e-5`, relative `5e-4`.

The final-update oracle does not independently reconstruct all 512 gradients. Replay identity is a same-device claim, not cross-GPU ZERO BIT. QGP1 is mandatory for exported results; exact restoration and numerical agreement remain distinct gates. The campaign did not promote a model checkpoint.

## Limits and provenance

The 24 GB → 8 GB objective remains a development direction, not a universal achievement. Larger models, layers and contexts require separately qualified resource and numerical contracts.

Private evidence inspected: `training-memory-v1` memory report, comparison summary, final status and training audit. Full measurements, checkpoints and implementation details are retained privately. This public summary cannot reproduce the private run by itself.
